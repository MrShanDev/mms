## ⚡️系统介绍

🔥🔥🔥模块化管理系统（Modular management
system），简称：MMS，是一款基于多应用模块用户、商品、支付、订单、分销、日志、定时、通信、直播、广告、文章等多模块应用开源系统，可快速的应用与各类项目研发中，定期更新功能修复、上新、技术栈分享 (
十年磨一剑，做最有价值的开源项目)！


> 项目代码、文档 均开源免费可商用 ,活到老写到老 为兴趣而开源 为学习而开源.


🍃系统演示: [传送门](/index/demo)

🍃MMS文档: [mmsAdmin](https://mmsadmin.cn/)
